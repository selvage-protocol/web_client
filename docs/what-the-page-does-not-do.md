# What the page does not do

No accounts, no analytics, no stored state beyond the live session, the remembered display name and
the tab's own note that it was hosting; no automatic rejoin or host reclaim. A test pins that the
guest path never asks for the host role and that the only mint is the one behind the folder picker.

`BROWSER_NOTES.md` used to carry the decisions, the bundle diet, and the one layer a human still has
to eyeball: Monaco rendering, which the proving host has no display for. That file is gone, and its
material lives in this tree: the bundle diet is [The build](the-build.md), the layer none of the
proofs covers is [Proofs](proofs.md), and the decisions are the prose around them.
