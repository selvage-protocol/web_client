# Languages and peer markers

A room path opens in the mode its type maps to: Markdown/MDX,
TypeScript/JavaScript, Rust, CSS/SCSS/Less, HTML, XML/SVG, YAML, shell, Python, Go, C/C++, Java,
SQL, Lua, INI, Dockerfile, PowerShell, Ruby, PHP, C#, Kotlin, Swift, Dart, R, Perl, Clojure,
GraphQL, Protobuf, HCL/Terraform, reStructuredText, CoffeeScript, Batch, and JSON, TOML and Nix.
Everything else stays `plaintext`.

A peer is drawn as a caret bar, a glyph-margin initials badge, a `label · role` hover, an
overview-ruler tick, and a fill while they hold a selection. The peer's whole line is never marked;
the VS Code client draws the same pair.
